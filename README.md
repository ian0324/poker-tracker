# Poker Tracker（PT4 風格・本機版）

只需要 Python 3（標準函式庫），不用安裝任何套件。

## 啟動

**桌面程式（建議）**：第一次先雙擊 `build.bat` 打包（需要網路，約 1–2 分鐘），會在上一層 `poker\` 產生 `PokerTracker.exe`。之後雙擊 exe 即可，會開一個獨立視窗，關閉視窗程式就結束。第一次執行若 Windows SmartScreen 攔截，選「其他資訊 → 仍要執行」。

**原始碼模式**：雙擊 `start.bat`（或 `python app.py`），會開瀏覽器 `http://localhost:8000`，Ctrl+C 結束。

兩種模式共用同一個 `hands` 資料夾與 `tracker\tracker.db`。

**更新程式**：exe 啟動時會優先讀取 `tracker\` 資料夾裡的 `.py` 與 `index.html`，所以之後程式更新只要重開 exe 即可，不用重新 build（只有 `main.py` 或需要新套件時才要重 build）。

## 匯入手牌

把 GGPoker 匯出的 .txt 手牌檔丟進 `poker\hands`（可含子資料夾，zip 請先解壓）。**程式每次啟動都會自動掃描並匯入新檔**；程式開著時放入新檔，則到「匯入」分頁按「開始匯入」。已匯入的手牌依 Hand ID 去重，重複匯入不會重複計算。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `parser.py` | 解析 GGPoker Rush & Cash 手牌格式，計算每人每手的投入/收回/淨利與統計旗標 |
| `db.py` | SQLite 存取與匯入（`tracker.db` 會自動建立在同資料夾） |
| `stats.py` | 統計查詢：整體、位置、169 起手牌、每日、盈虧曲線、手牌列表、對手 |
| `app.py` | 本機 HTTP 伺服器與 JSON API、啟動自動匯入 |
| `main.py` | 桌面視窗入口（pywebview），打包成 exe 用 |
| `paths.py` | 決定 hands／資料庫位置（原始碼與 exe 兩種模式） |
| `build.bat` | 打包成 `PokerTracker.exe` |
| `index.html` | 前端介面 |

## 統計定義

- **VPIP**：翻前主動投錢（跟注或加注）的手數比例。
- **PFR**：翻前加注的手數比例。
- **3-Bet**：面對一次加注時再加注的比例（分母＝有機會 3-bet 的手數）。
- **Fold to 3-Bet**：自己開池後被 3-bet 時棄牌的比例。
- **C-Bet**：翻前最後加注者在翻牌圈第一個下注的比例。
- **Fold to C-Bet**：面對翻牌 C-bet 時棄牌的比例。
- **WTSD**：看到翻牌後走到攤牌的比例。
- **W$SD**：攤牌時贏錢的比例。
- **WWSF**：看到翻牌後最終贏下底池的比例。
- **AF**：(下注＋加注) ÷ 跟注，翻牌後。
- **Steal**：CO/BTN/SB 在前面全棄時首入加注的比例。
- **bb/100**：每 100 手贏的大盲數。
- 淨利已扣除抽水與 Jackpot 費用（每手各玩家淨利加總 = −抽水−Jackpot，已驗證）。

## 情境篩選（篩選列）

- **底池類型**：Limped（翻前無人加注）/ SRP（一次加注）/ 3BP（兩次）/ 4BP+（三次以上）。
- **角色**：Raiser＝翻前最後一個加注的人；Caller＝翻前有投錢但不是最後加注者。
- **IP/OOP**：只看有看到翻牌的手，IP＝翻牌後最後行動的人。
- **翻牌人數**：HU＝2 人看翻牌；多人＝3 人以上。
- **翻前首個動作**：你翻前第一個自主動作的分類（Open / Iso / 3-Bet / 4-Bet / Call / Call vs 3-bet / Limp / Fold）。

例：查「SRP as raiser、IP」→ 底池選 SRP、角色選 Raiser、IP/OOP 選 IP，按套用。

## 翻前範圍圖

選位置與動作後顯示 169 格頻率：「首入」＝你行動時前面沒人加注；「面對加注」＝前面剛好一次加注。這一頁只套用日期篩選。

## 翻前策略（剝削型範圍）

`ranges.py` 放的是針對 NL5 Rush & Cash 池子的建議範圍：各位置首入開池範圍，以及「我開池 × 對方 3-bet 位置」的 4-bet／跟注／棄牌決策表。分頁上底色＝建議動作，格內數字＝你的實際次數，黃框＝你的做法與建議相反（樣本足夠時）；點格子跳到那些手牌。「訓練模式」隨機出題（首入／面對 3-bet），答對率與錯題存在瀏覽器（localStorage）。要調整範圍直接改 `ranges.py` 的字串，重開程式即可。

## 漏洞檢查

「漏洞檢查」分頁列出預設的問題手牌群組（OOP 強牌只 check-call、3-bet 底池聽牌只 check-call、IP 強牌只跟、面對 3-bet 棄掉強牌、範圍外跟注 3-bet、河牌跟注輸掉、凌晨虧損等），點一列直接跳到手牌列表。

篩選列的「翻牌牌力」（set／兩對／頂對／聽牌…）和「翻牌動作線」（check-call／check-raise／bet…）可以自由組合，例如「OOP + 強牌 + check-call」。

## 回放器

點任一手牌開啟桌面回放：Hero 固定在下方，座位顯示玩家／位置／籌碼（bb）與對手 HUD（手數 · VPIP/PFR/3-Bet）。下方 ← → 一次一個動作（鍵盤左右鍵也可以），翻前／翻牌／轉牌／河牌／結果快速跳轉；桌中央顯示底池與下一位行動者面對的底池賠率。右側是同場次的手牌清單，點擊直接切換。文字紀錄收在「文字紀錄」可展開。

## 其他分頁

- **牌力**：看到翻牌的手依翻牌牌力分組，顯示手數、淨利、IP/OOP、翻牌動作比例（bet/raise/call/fold）、WTSD、W$SD。點一列跳到該組手牌。
- **場次**：依時間間隔（預設 30 分鐘）切成場次，顯示時長、手數、手/小時、淨利、All-in EV、bb/100。
- **標記**：在回放視窗按 ★ 或寫筆記的手牌集中列在這裡。
- **All-in EV**：翻前／翻牌／轉牌全下且所有人底牌已知時，用勝率算期望值；盈虧圖灰線是 EV 線，手牌列表「EV差」欄＝EV − 實際（正值代表運氣不好）。
- 手牌列表的動作縮寫：R12＝加注到 12bb、B53＝下注到 53bb、C＝跟注、X＝過牌、F＝棄牌、!＝全下；後面灰字是該街結束時的底池大小。

## 重建資料庫

刪掉 `tracker.db` 再重新匯入即可。注意：★ 標記與筆記存在 `tracker.db` 的 notes 表，重建會一併清掉；要保留請先備份 `tracker.db`。
